## 你需要了解的内容

- 通过二维码将 Keycard Shell 与 Bitcoin-Safe 配合使用，无需厂商应用。
- 密钥在 Keycard 的安全元件中生成并保存。Shell 读取 PSBT，在自己的屏幕上显示交易，并且只有在你在设备上确认后才会签名。
- 支持多签（P2WSH）和完整的 PSBT 流程。请注册多签描述符，并为 Bitcoin-Safe 导出签名设备数据。
- 签名前，请在 Shell 屏幕上核对每个输出和手续费。
