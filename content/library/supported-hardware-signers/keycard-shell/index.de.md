## Was Sie erwarten sollten

- Verwenden Sie Keycard Shell mit Bitcoin-Safe über QR; eine Hersteller-App ist nicht erforderlich.
- Schlüssel werden auf dem Secure Element der Keycard erzeugt und dort gespeichert. Shell liest die PSBT, zeigt die Transaktion auf dem eigenen Bildschirm an und signiert erst, nachdem Sie auf dem Gerät bestätigt haben.
- Multisig (P2WSH) und vollständige PSBT-Workflows werden unterstützt. Registrieren Sie den Multisig-Deskriptor und exportieren Sie die Signaturgeber-Daten für Bitcoin-Safe.
- Prüfen Sie vor dem Signieren jeden Ausgang und die Gebühr auf dem Bildschirm von Shell.
