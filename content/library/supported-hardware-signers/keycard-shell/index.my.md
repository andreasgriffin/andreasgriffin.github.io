## မျှော်လင့်ရမည်များ

- QR ဖြင့် Keycard Shell ကို Bitcoin-Safe နှင့်အတူ အသုံးပြုပါ။ ထုတ်လုပ်သူ app မလိုအပ်ပါ။
- သော့များကို Keycard ၏ secure element ပေါ်တွင် ဖန်တီးပြီး သိမ်းဆည်းထားသည်။ Shell သည် PSBT ကို ဖတ်ပြီး ငွေပေးချေမှုကို ၎င်း၏ စခရင်ပေါ်တွင် ပြသကာ စက်ပေါ်တွင် အတည်ပြုပြီးမှသာ လက်မှတ်ထိုးသည်။
- Multisig (P2WSH) နှင့် PSBT workflow အပြည့်အစုံကို ထောက်ပံ့သည်။ multisig descriptor ကို register လုပ်ပြီး Bitcoin-Safe အတွက် signer data ကို export လုပ်ပါ။
- လက်မှတ်မထိုးမီ Shell စခရင်ပေါ်တွင် output တိုင်းနှင့် fee ကို စစ်ဆေးပါ။
