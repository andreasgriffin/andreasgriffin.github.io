## Yang perlu diharapkan

- Gunakan Keycard Shell dengan Bitcoin-Safe melalui QR; tidak perlu aplikasi vendor.
- Kunci dibuat dan disimpan di elemen aman Keycard. Shell membaca PSBT, menampilkan transaksi di layarnya sendiri, dan menandatangani hanya setelah Anda mengonfirmasi di perangkat.
- Alur multisig (P2WSH) dan PSBT lengkap didukung. Daftarkan descriptor multisig dan ekspor data penanda tangan untuk Bitcoin-Safe.
- Verifikasi setiap output dan biaya di layar Shell sebelum menandatangani.
