## အကျဉ်းချုပ်

[ထိခိုက်နေသော COLDCARD firmware များရှိ seed ဖန်တီးမှုဆိုင်ရာ ပြင်းထန်သော အားနည်းချက်ကို Coinkite က ထုတ်ဖော်ခဲ့သည်](https://blog.coinkite.com/coldcard-mk3-seed-generation-warning/)။ [Block ၏ နည်းပညာဆိုင်ရာ သုံးသပ်ချက်](https://engineering.block.xyz/blog/predictable-rng-fallback-and-32-bit-reseed-in-coldcard-firmware) သည် ကိရိယာ၏ hardware RNG အစား အသုံးပြုထားသော ခန့်မှန်းနိုင်သည့် software ကျပန်းနံပါတ်ထုတ်စက်ကို အကြောင်းရင်းအဖြစ် ဖော်ထုတ်ခဲ့ပြီး **တိုက်ခိုက်မှုများ တက်ကြွစွာ ဖြစ်ပွားနေသည်** ဟု သတိပေးထားသည်။ Firmware update လုပ်ခြင်းသည် ရှိပြီးသား seed ကို **မပြုပြင်ပေးနိုင်**ပါ။

**ထိခိုက်နေသော Coinkite ကိရိယာတွင် seed တစ်ခုဖန်တီးထားပါက သင့်ငွေများကို seed အသစ်သို့ ရွှေ့ပြောင်းပါ။**

## ကျွန်ုပ်၏ ကိရိယာ ထိခိုက်နေပါသလား။

ထိခိုက်မှုသည် ကိရိယာ ထုတ်လုပ်သည့်အချိန်ပေါ်တွင် မမူတည်ဘဲ **seed ဖန်တီးချိန်၌ ထည့်သွင်းထားသော firmware ဗားရှင်းပေါ်တွင်** မူတည်သည်။

| ကိရိယာ | seed ဖန်တီးရန် အသုံးပြုခဲ့သော firmware | အခြေအနေ |
|---|---|---|
| Mk1 | ထုတ်ဝေခဲ့သော firmware အားလုံး | ထိခိုက်မှုမရှိ |
| Mk2 / Mk3 | v3.2.2 သို့မဟုတ် အစောပိုင်း | ထိခိုက်မှုမရှိ (hardware RNG အသုံးပြုသည်) |
| Mk2 / Mk3 | v4.0.0 – v4.1.9 | **ထိခိုက်နိုင်သည်** — လုံခြုံသော reseed မရှိ |
| Mk4 | ထုတ်လုပ်မှု v5.0.0 နှင့် နောက်ပိုင်း | **ထိခိုက်နိုင်သည်** — ခန့်မှန်းခြေ ဘစ် 72 ဖြင့် ကန့်သတ်ထား |
| Q | ထုတ်လုပ်မှု firmware အားလုံး | **ထိခိုက်နိုင်သည်** — ခန့်မှန်းခြေ ဘစ် 72 ဖြင့် ကန့်သတ်ထား |
| Mk5 | ထုတ်လုပ်မှု firmware အားလုံး | **ထိခိုက်နိုင်သည်** — ခန့်မှန်းခြေ ဘစ် 72 ဖြင့် ကန့်သတ်ထား |
| TAPSIGNER, OPENDIME, SATSCARD | — | ထိခိုက်မှုမရှိ (ကုဒ်အခြေခံ မတူညီ) |

မလုံခြုံသော seed ကို ထုတ်ယူပြီး အခြားပိုက်ဆံအိတ်သို့ တင်သွင်းခြင်းက **မပြုပြင်ပေးနိုင်ကြောင်း** သတိပြုပါ — seed ကိုယ်တိုင် ထိခိုက်နေဆဲဖြစ်သည်။

## seed အသစ်မဖန်တီးမီ ပြုပြင်ထားသော firmware ကို ထည့်သွင်းပါ

ပြုပြင်ထားသော firmware ကို ထိခိုက်နေသော မော်ဒယ်တိုင်းနှင့် ဖြန့်ချိမှုလမ်းကြောင်းတိုင်းအတွက် ယခုရရှိနိုင်ပြီ ဖြစ်သည်။ ၎င်းကို မထည့်သွင်းမချင်း COLDCARD တွင် seed အသစ် မဖန်တီးပါနှင့်။

| ကိရိယာ | ပြုပြင်ထားသော firmware |
|---|---|
| Mk2 / Mk3 | 4.2.0 သို့မဟုတ် နောက်ပိုင်း |
| Mk4 / Mk5 (standard) | 5.6.0 သို့မဟုတ် နောက်ပိုင်း |
| Q (standard) | 1.5.0Q သို့မဟုတ် နောက်ပိုင်း |
| Mk4 / Mk5 (Edge) | 6.6.0X သို့မဟုတ် နောက်ပိုင်း |
| Q (Edge) | 6.6.0QX သို့မဟုတ် နောက်ပိုင်း |

Standard နှင့် Edge သည် သီးခြား ဖြန့်ချိမှုလမ်းကြောင်းများ ဖြစ်သည်။ Edge ကို အသုံးပြုပါက သင့်မော်ဒယ်အတွက် ပြုပြင်ထားသော Edge ဗားရှင်းကို ထည့်သွင်းပါ — standard ဗားရှင်းထက် ဗားရှင်းနံပါတ် မြင့်နေရုံဖြင့် အဟောင်းဖြစ်သော Edge 6.x ဗားရှင်းကို ပြုပြင်ပြီးဖြစ်သည်ဟု မယူဆပါနှင့်။

## အန်စာတုံးလှိမ့်မှုများ သို့မဟုတ် စကားဝှက်စာပိုဒ်က ကျွန်ုပ်ကို ကာကွယ်ပေးပါသလား။

- **အန်စာတုံးလှိမ့်မှုများ:** ဤ bug သည် ကိရိယာမှ ထုတ်ပေးသော entropy ကိုသာ သက်ရောက်သည်။ seed ဖန်တီးရာတွင် အနည်းဆုံး **လွတ်လပ်ပြီး သီးသန့်သော အန်စာတုံးလှိမ့်မှု အကြိမ် 50** ထည့်သွင်းခဲ့ပါက (ခန့်မှန်းခြေ ဘစ် 256 entropy အတွက် အကြိမ် 99 သို့မဟုတ် ပို၍)၊ အန်စာတုံးထည့်သွင်းမှုတစ်ခုတည်းက အနည်းဆုံး လွတ်လပ်သော entropy ဘစ် 128 ကို ထည့်ဝင်ထားပြီး ဤပြဿနာတစ်ခုတည်းကြောင့် အဆိုပါ seed သည် အန္တရာယ်ရှိသည်ဟု မယူဆပါ။ လှိမ့်မှု အကြိမ် 50 အောက်ဖြစ်ပါက — သို့မဟုတ် မည်မျှထည့်သွင်းခဲ့သည် သို့မဟုတ် သီးသန့်ဖြစ်ခဲ့မဖြစ်ခဲ့ မသေချာပါက — **ရွှေ့ပြောင်းပါ**။
- **BIP-39 စကားဝှက်စာပိုဒ်:** ခိုင်မာပြီး ထူးခြားသော BIP-39 စကားဝှက်စာပိုဒ် (COLDCARD PIN မဟုတ်) သည် လွတ်လပ်သော အကာအကွယ်တစ်ခုကို ပေါင်းထည့်သော်လည်း ထိခိုက်နေသော seed ကို **မပြုပြင်ပေးနိုင်**ပါ။ သင့်စကားဝှက်စာပိုဒ်သည် အတို၊ အသုံးများ၊ ပြန်သုံးထား၊ သို့မဟုတ် ခန့်မှန်းရလွယ်ကူပါက — သို့မဟုတ် ၎င်း၏ခိုင်ခံ့မှုကို မသေချာပါက — ငွေများကို အန္တရာယ်ရှိသည်ဟု သတ်မှတ်ပြီး ချက်ချင်း ရွှေ့ပြောင်းပါ။ ခိုင်မာသော စကားဝှက်စာပိုဒ် ရှိသည့်တိုင် တတ်နိုင်သမျှ မြန်မြန် အသစ်ဖန်တီးထားသော seed သို့ ရွှေ့ပြောင်းပါ။

## ရွှေ့ပြောင်းမှု စစ်ဆေးစာရင်း

အေးအေးဆေးဆေးနှင့် ဂရုတစိုက် ရွှေ့ပြောင်းပါ။ ပိုက်ဆံအိတ် ရွှေ့ပြောင်းမှုကို အလျင်စလို လုပ်ခြင်းသည် သင်ဖြေရှင်းနေသော ပြဿနာထက် ပိုမိုချက်ချင်းအန္တရာယ် ဖြစ်စေနိုင်သည်။

1. အစားထိုး seed မဖန်တီးမီ သင့်မော်ဒယ်အတွက် **ပြုပြင်ထားသော firmware ကို ထည့်သွင်း**ပါ။ လိုလျှင် seed အသစ်ကို **COLDCARD မဟုတ်သော လက်မှတ်ရေးထိုးကိရိယာ**တွင် ဖန်တီးနိုင်သည် ([ပံ့ပိုးထားသော ကိရိယာများကို ကြည့်ပါ]({{< ref "library/supported-hardware-signers" >}})) — မည်သည့်နည်းဖြင့်ဖြစ်စေ seed အဟောင်းကို **ပြန်မသုံးပါနှင့်**။
2. လုံးဝအသစ်သော seed တစ်ခုကို ဖန်တီးပြီး **မှတ်တမ်းတင်ပါ**။ ငွေမသွင်းမီ စာဖြင့်ရေးထားသော မိတ္တူကူး၊ ပိုက်ဆံအိတ် fingerprint နှင့် လက်ခံလိပ်စာတစ်ခုကို စစ်ဆေးပါ။
3. Bitcoin-Safe ၏ စနစ်တည်ဆောက်မှု wizard ကို အသုံးပြု၍ seed အသစ်ဖြင့် [လက်မှတ်တစ်စောင်တည်း ပိုက်ဆံအိတ်]({{< ref "library/setup-singlesig-wallet" >}}) သို့မဟုတ် [လက်မှတ်အများအပြား ပိုက်ဆံအိတ်]({{< ref "library/setup-multisig-wallet" >}}) အသစ်ကို ဖန်တီးပါ။
4. wizard ၏ လက်ခံ-နှင့်-ပို့ခြင်း စစ်ဆေးမှုကို ပြီးမြောက်ပါ။ လက်မှတ်ရေးထိုးကိရိယာအသစ်တွင် မိတ္တူကူးနှင့် လက်ခံလိပ်စာကို စစ်ဆေးပါ၊ စမ်းသပ်ငွေ အနည်းငယ် လက်ခံပါ၊ ထို့နောက် ပိုက်ဆံအိတ်အသစ်ရှိ အခြားစစ်ဆေးပြီးသား လိပ်စာသို့ အောင်မြင်စွာ ပြန်ပို့ပါ။
5. ရွှေ့ပြောင်းမှု ငွေပေးငွေယူကို လက်မှတ်ရေးထိုး၍ ထုတ်လွှင့်ပါ။
   - **လက်မှတ်တစ်စောင်တည်း ပိုက်ဆံအိတ်:** လျင်မြန်စွာ အတည်ပြုနိုင်ရန် မြင့်မားသော အခကြေးငွေဖြင့် ပုံမှန်ထုတ်လွှင့်ပါ။
   - **လက်မှတ်အများအပြား ပိုက်ဆံအိတ်:** အများပြည်သူ mempool တွင် ၎င်း၏ public keys များ ပေါ်လွင်စေသောကြောင့် ပုံမှန်ထုတ်လွှင့်ခြင်း မပြုပါနှင့်။ လက်မှတ်ရေးထိုးပြီးသား raw ငွေပေးငွေယူကို ကူးယူပြီး [MARA Slipstream](https://slipstream.mara.com/) မှတစ်ဆင့် တိုက်ရိုက်တင်သွင်းပါ။
6. **လက်ကျန်ငွေ အပြည့်အစုံ** ပိုက်ဆံအိတ်အသစ်သို့ ရောက်ရှိ၍ အတည်ပြုပြီးသည့်အထိ COLDCARD အဟောင်းနှင့် ၎င်း၏ မိတ္တူကူးကို သိမ်းထားပါ။ ထို့နောက်မှသာ seed အဟောင်းကို ဖျက်ပါ။

Mk2/Mk3 သည် သင့်တစ်ခုတည်းသော လက်မှတ်ရေးထိုးကိရိယာဖြစ်ပါက firmware 4.2.0 သို့မဟုတ် နောက်ပိုင်းကို အရင်ထည့်သွင်းပါ — ၎င်းသည် အစားထိုး seed များကို မှန်ကန်စွာ ဖန်တီးပေးသောကြောင့် ရွှေ့ပြောင်းမှုကို ပြီးမြောက်ရန် COLDCARD အသစ်မလိုအပ်ပါ။ တစ်ခုတည်းသော ကိရိယာတွင် seed အဟောင်းနှင့် အသစ်ကြား ဂရုတစိုက် လှည့်ပတ်အသုံးပြုကာ အဆင့်များအတိုင်း လိုက်နာပြီး ရွှေ့ပြောင်းမှု အပြည့်အဝ အတည်ပြုချိန်အထိ မိတ္တူကူးအဟောင်းကို သိမ်းထားပါ။

## လက်မှတ်အများအပြား သုံးပါက

လက်မှတ်အများအပြား ဖွဲ့စည်းမှုတွင် ထိခိုက်နေသော ကိရိယာများ **သီးသန့်သာ** ပါဝင်ပါက အားနည်းချက်သည် ဆက်လက်သက်ရောက်နေဆဲ ဖြစ်သည်။ ထိခိုက်မှုမရှိသော လက်မှတ်ရေးထိုးကိရိယာ အနည်းဆုံးတစ်ခုပါဝင်သည့် quorum ဖြင့် ဖွဲ့စည်းမှုကို ကာကွယ်ပါ။

## အခြားသူတစ်ဦး၏ ရွှေ့ပြောင်းမှုကို ကူညီခြင်း

သူတို့၏ seed စကားလုံးများကို မျှဝေရန်၊ ဓာတ်ပုံရိုက်ရန်၊ သို့မဟုတ် ရိုက်ထည့်ရန် ဘယ်တော့မှ မတောင်းဆိုပါနှင့်။ seed သည် သီးသန့်ဖြစ်နေရမည်ဖြစ်ပြီး လက်မှတ်ရေးထိုးကိရိယာပေါ်တွင်သာ ထည့်သွင်းရမည် ဖြစ်သည်။
