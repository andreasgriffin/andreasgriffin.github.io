## 요약

[Coinkite는 영향을 받는 COLDCARD 펌웨어의 시드 생성에서 치명적인 취약점을 공개했습니다](https://blog.coinkite.com/coldcard-mk3-seed-generation-warning/). [Block의 기술 분석](https://engineering.block.xyz/blog/predictable-rng-fallback-and-32-bit-reseed-in-coldcard-firmware)은 기기의 하드웨어 RNG 대신 사용된 예측 가능한 소프트웨어 난수 생성기가 원인임을 밝혀냈으며, **적극적인 악용이 진행 중**이라고 경고합니다. 펌웨어를 업데이트해도 기존 시드는 **복구되지 않습니다**.

**영향을 받는 Coinkite 기기에서 시드를 만든 경우, 자금을 새 시드로 옮기세요.**

## 내 기기가 영향을 받나요?

영향 여부는 기기의 제조 시기가 아니라 **시드를 생성할 당시 설치된 펌웨어 버전**에 따라 달라집니다.

| 기기 | 시드 생성에 사용된 펌웨어 | 상태 |
|---|---|---|
| Mk1 | 출시된 모든 펌웨어 | 영향 없음 |
| Mk2 / Mk3 | v3.2.2 이하 | 영향 없음 (하드웨어 RNG 사용) |
| Mk2 / Mk3 | v4.0.0 – v4.1.9 | **취약** — 안전한 reseed 없음 |
| Mk4 | 프로덕션 v5.0.0 이후 | **취약** — 약 72비트 엔트로피로 제한 |
| Q | 모든 프로덕션 펌웨어 | **취약** — 약 72비트 엔트로피로 제한 |
| Mk5 | 모든 프로덕션 펌웨어 | **취약** — 약 72비트 엔트로피로 제한 |
| TAPSIGNER, OPENDIME, SATSCARD | — | 영향 없음 (다른 코드베이스) |

안전하지 않은 시드를 내보내 다른 지갑으로 가져와도 **수정되지 않는다는 점**을 기억하세요. 시드 자체는 계속 영향을 받습니다.

## 새 시드를 생성하기 전에 수정된 펌웨어를 설치하세요

수정된 펌웨어는 이제 영향을 받는 모든 모델과 릴리스 트랙에서 사용할 수 있습니다. 설치하기 전에는 COLDCARD에서 새 시드를 생성하지 마세요.

| 기기 | 수정된 펌웨어 |
|---|---|
| Mk2 / Mk3 | 4.2.0 이상 |
| Mk4 / Mk5 (standard) | 5.6.0 이상 |
| Q (standard) | 1.5.0Q 이상 |
| Mk4 / Mk5 (Edge) | 6.6.0X 이상 |
| Q (Edge) | 6.6.0QX 이상 |

Standard와 Edge는 별도의 릴리스 트랙입니다. Edge를 사용한다면 모델에 맞는 수정된 Edge 릴리스를 설치하세요. 표준 릴리스보다 버전 번호만 높다고 해서 오래된 Edge 6.x 릴리스가 수정되었다고 가정하지 마세요.

## 주사위 굴림 또는 패스프레이즈가 나를 보호하나요?

- **주사위 굴림:** 이 버그는 기기가 생성하는 엔트로피에만 영향을 미칩니다. 시드를 만들 때 **독립적이고 비공개적인 주사위 굴림을 최소 50회** 입력했다면 (약 256비트 엔트로피를 위해서는 99회 이상), 주사위 입력만으로 최소 128비트의 독립 엔트로피가 확보되므로 이 문제만으로는 시드가 위험하다고 간주되지 않습니다. 50회 미만이거나 — 몇 회를 입력했는지, 비공개였는지 확실하지 않다면 — **옮기세요**.
- **BIP-39 패스프레이즈:** 강력하고 고유한 BIP-39 패스프레이즈(COLDCARD PIN이 아님)는 독립적인 방어막을 추가하지만, 영향을 받은 시드는 **수정하지 못합니다**. 패스프레이즈가 짧거나, 흔하거나, 재사용되었거나, 추측 가능하거나 — 강도를 확신할 수 없다면 — 자금이 위험에 노출된 것으로 간주하고 즉시 옮기세요. 강력한 패스프레이즈를 사용하더라도 가능한 한 빨리 새로 생성한 시드로 옮기세요.

## 마이그레이션 체크리스트

침착하고 신중하게 옮기세요. 지갑 마이그레이션을 서두르면 해결하려는 문제보다 더 즉각적인 위험이 생길 수 있습니다.

1. 교체용 시드를 생성하기 전에 모델의 **수정된 펌웨어를 설치**하세요. 원한다면 **COLDCARD가 아닌 서명 기기**에서 새 시드를 생성할 수 있습니다 ([지원 기기 참조]({{< ref "library/supported-hardware-signers" >}})). 어느 쪽이든 이전 시드는 **재사용하지 마세요**.
2. 완전히 새로운 시드를 생성하고 **기록**하세요. 자금을 입금하기 전에 서면 백업, 지갑 지문, 수신 주소를 검증하세요.
3. Bitcoin-Safe 설정 마법사를 사용하여 새 시드로 새 [단일 서명 지갑]({{< ref "library/setup-singlesig-wallet" >}}) 또는 [다중 서명 지갑]({{< ref "library/setup-multisig-wallet" >}})을 만드세요.
4. 마법사의 수신·송금 테스트를 완료하세요. 새 서명 기기에서 백업과 수신 주소를 검증하고, 소액의 테스트 금액을 받아 새 지갑의 검증된 다른 주소로 성공적으로 송금하세요.
5. 마이그레이션 트랜잭션에 서명하고 브로드캐스트하세요.
   - **단일 서명 지갑:** 수수료를 높게 설정하여 빠르게 확인되도록 정상적으로 브로드캐스트하세요.
   - **다중 서명 지갑:** 공개 메모리풀에 공개 키가 노출되므로 정상적으로 브로드캐스트하지 마세요. 서명된 원시 트랜잭션을 복사하여 [MARA Slipstream](https://slipstream.mara.com/)을 통해 직접 제출하세요.
6. **전체 잔액**이 새 지갑에 도착하여 확인될 때까지 기존 COLDCARD와 백업을 보관하세요. 그 후에만 이전 시드를 지우세요.

Mk2/Mk3이 유일한 서명 기기라면 먼저 펌웨어 4.2.0 이상을 설치하세요. 교체용 시드를 올바르게 생성하므로 마이그레이션을 완료하기 위해 더 새로운 COLDCARD가 필요하지 않습니다. 동일한 단계를 따르되 한 대의 기기에서 이전 시드와 새 시드를 신중하게 번갈아 사용하고, 마이그레이션이 완전히 확인될 때까지 이전 백업을 보관하세요.

## 다중 서명을 사용하는 경우

다중 서명 구성이 영향을 받는 기기**로만** 구성되어 있다면 취약점은 여전히 적용됩니다. 영향을 받지 않는 서명 기기를 최소 하나 포함하는 쿼럼으로 구성을 보호하세요.

## 다른 사람의 마이그레이션을 돕는 경우

그들에게 시드 단어를 공유, 촬영, 입력하도록 요청하지 마세요. 시드는 비밀로 유지되어야 하며 서명 기기 자체에만 입력되어야 합니다.
